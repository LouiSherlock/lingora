# Lingora

**你的专属英语练习空间。** 说出想练什么，AI 现场出题；做完就改，错了就问。

Lingora 是一个面向中文学习者的英语练习应用。它不像题库那样让你在固定题目里打转，而是根据你的目标等级、想练的知识点和当天的心情，实时生成一套只属于你的练习：题干是英文，解析是中文，做完立刻判分，还能把 AI 助教叫出来追问「为什么选这个」。

---

## 它解决什么问题

- **题库刷腻了**：固定题目容易背答案，Lingora 每次生成新题，同一知识点换不同考法。
- **不知道自己错在哪**：每题都有中文解析，结果页会汇总「优先复习」的知识点。
- **错题没人讲**：答题页内置 AI 助教，结合当前题目、你的答案和解析流式答疑。
- **配置太麻烦**：API Key 全在服务端，浏览器只负责选模型。

## 核心功能

### 1. 三十秒开始
首页直接选目标等级（A1–C2），点「开始练习」进入创建页。背景是漂移的英文词云，鼠标划过会散开。

### 2. 按需定制练习
- **学习类型**：语法 / 词汇
- **英语等级**：A1、A2、B1、B2、C1、C2
- **知识点**：每个等级内置按主题分组的语法与词汇清单（A1 到 C2 共 50+ 个语法分组），也可以打开「手动输入主题」直接写
- **难度**：简单 / 普通 / 困难
- **题量**：5 / 10 / 15 / 20 题
- **自定义要求**：例如「重点考察容易混淆的时态用法」

### 3. AI 出题
生成三种题型，题量 ≥ 3 时会要求三种题型都覆盖：

| 题型 | 说明 |
| --- | --- |
| 单项选择 | 3–4 个选项，答案为选项 key |
| 填空 | 一个短单词或短语 |
| 判断 | 选项固定为「正确 / 错误」 |

生成后会做格式归一化、去重、答案校验；题型覆盖不足时自动发起一次修复请求，仍然失败也不会让你空手而归。

### 4. 边做边学
- 提交即判分，答对撒彩带
- 进度条按「已提交」统计，可跳过题目
- 答错直接展示正确答案与中文解析
- 每题标注知识点

### 5. AI 助教
答题页的「AI 助教」是一个流式对话面板，默认把当前题目、正确答案、选项带进上下文。历史对话保存在本次练习里（最多 40 条），刷新页面不会丢。

### 6. 结果页与针对性复习
- 总分、正确率、待复习题数
- 「优先复习」：所有错题涉及的知识点去重汇总
- 逐题解析：你的答案 vs 正确答案 + 讲解
- **根据错题再练一轮**：把错题重新组一套更短的练习
- **根据错题重新生成新题**：让 AI 参照错题（最多 5 道样例、约 12k 字符上下文）出同类型的新题

### 7. 模型可选，密钥不落地
设置面板从服务端拉取可用模型列表，选择结果只保存在浏览器；API Key 与接口地址始终留在服务端。

## 使用流程

```
首页（选等级）
  └─ 创建练习（类型 / 等级 / 知识点 / 难度 / 题量）
       └─ 生成中…
            └─ 答题（即时判分 · AI 助教）
                 └─ 结果（分数 / 解析 / 错题再练）
```

答题状态存在 `sessionStorage`，刷新页面可以继续；关闭标签页即清空。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 框架 | Next.js 16（App Router、Turbopack、Cache Components） |
| UI | React 19、Astryx 设计系统（StyleX）、Tailwind v4（主题 token 桥接） |
| 状态 | Zustand（持久化到 sessionStorage） |
| AI | Vercel AI SDK + OpenAI 兼容接口（服务端单例客户端） |
| 动效 | Motion、p5（首页词云）、canvas-confetti |
| 测试 | Vitest（`tests/`） |

## 快速开始

要求：Node.js 20+、pnpm 11。

```bash
pnpm install
```

在项目根目录创建 `.env`：

```bash
# 必填：服务端调用 AI 的密钥，永远不会下发到浏览器
PROVIDER_API_KEY=your-api-key

# 选填：OpenAI 兼容接口地址
PROVIDER_BASE_URL=https://your-endpoint/v1
```

启动开发服务器：

```bash
pnpm dev        # http://localhost:3000
```

首次使用请在右上角「设置」里选择模型（或直接填写模型名称）。

## 目录结构

```
src/
  app/                    App Router 页面与 API
    page.tsx              首页（等级选择 + 词云）
    practice/create/      创建练习
    practice/session/[id] 答题
    practice/result/[id]  结果与解析
    api/generate/         生成题目
    api/explain/          助教流式回答
    api/models/           可用模型列表
  components/             首页、设置面板、助教面板、生成动画等
  lib/
    ai/                   AI 客户端、提示词、错误映射、题目归一化
    practice-data.ts      题目与练习类型
    practice-grade.ts     判分规则（唯一来源）
  stores/                 Zustand 学习状态
  themes/lingora/         生成的主题 CSS（勿手改）
tests/                    Vitest 测试
```

## 一些约定

- 界面文案是中文；只有题目本身（题干、选项）用英文。
- 只有暗色主题，不提供切换。
- 没有数据库和账号体系：练习与设置都保存在当前标签页。
- 判分逻辑只在 `src/lib/practice-grade.ts`，页面不自行比较答案。
